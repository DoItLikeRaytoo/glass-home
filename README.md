# Glass Home

Eigene Startseite (Launcher) für den Samsung S95F (Tizen 9), im Stil von Apple tvOS mit Liquid-Glass-Karte.

- App-Code: `app/`
- Neue Version: Versionsnummer in `app/config.xml` erhöhen, Tag `vX.Y.Z` pushen → GitHub baut `GlassHome.wgt` und legt das Release an.
- Installation am TV: TizenBrew Installer → Install from GitHub → `DoItLikeRaytoo/glass-home`
